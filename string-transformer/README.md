String transformer is a program which applies six different transformtion of  user input to either upper, lower case, titlecase, snakecase e.t.c when run.


How to run it
- Save the program in main.go or any other file you named
- Run the program using: go run main.go
- Input a the text to transform
- The program run until you type "exit"

The program support the following transformation

upper : Convert all letters to uppercase
lower : Convert all letters to lowercase
cap : Capitalize the first lettermof every word, the rest lowercase
title : Like cap but small words remain lower
snake Converts text to snake_case, lowercase, removes symbol
reverse : Reverses each word individually
