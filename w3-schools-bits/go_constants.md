***Constants***


Constants are values that is not altered during the programe execution,. that is they can not be change ones declared.

***Declaring a constants***
Constant can only be declared using the const keyword

***Constant Types***
There are two types of constants:

- Typed constants: They are declared with a defined type

- Untyped constants: They are declared without a type


***Code Snippet***
```
func main() {
    const pi float32 = 3.142
}

func main() {
    const pi := 3.142
}
```
