***Comments***

Comments are the text in our code that is been ignored by the compiler during compilation

-  Comments can be used to explain the code, and to make it readable.

- Comments can also be used to comment out our code to prevent the code execution when trying to executing an alternative cod.


***Types of comments***
- Single line comments which start with a double foreword slash //
- multi-line comments which start with a foreword slash and asteric /*  */


***Code Snippet***
``
package main
import ("fmt")

// This print hello word to the screen
func main() {
  fmt.Println("Hello World!")
}
``
