***Data Types***

Data Type

Data type specifies the size and type of variable values.

***Basic go data type***
There are three basic data types
- Numeric : This represent integer type, floating point values and complex types
- bool : This represent a boolean value and must to be either true or false
- string :  Represent a string value

***Boolean Data Type***
A boolean data type is declared with the bool keyword and can only take the values true or false.
The default value of a boolean data type is false.

***Integer Data Type***
Integer data types are used to store a number without decimals, e.g 42, -24 

The integer data type has two categories:
- Signed integers (int) - can store both positive and negative values
- Unsigned integers (uint) - can only store non-negative values

***Float Data Types***
The float data types are use to store both positive and negative numbers  with decimal points e.g 3.142, -45.0

The datatypes has two keywords:
float32 = 32bits
float64 = 64bits

***String Data Type***
The datatyp use to store sequence of characters and the character in use must be close in double quotes("")
