Arrays

Arrays are use to declare multiple value of thesame type in a single variable.,instead  of declaring each variable separatly

***Declaring Array***
Array are declared using:

1. var key word
2. with the := sign


***Code Snippet***
```
func main() {
    var num_pupils = [7]{1,2,3,4,5,6,7}
    num_pupils = [3]{4,5,3}
}
```
